# 黑貓飲食指南｜星空視覺設計系統

> 主題基準：高貴、安靜、深邃的星空宇宙。星空是整個品牌的共通背景；分類色只作為辨識與互動強調，不得破壞整體一致性。

## 1. 品牌氛圍
- 核心意象：午夜星空、深藍星雲、微光星塵、香檳金。
- 關鍵感受：高級、沈穩、神秘、精緻、溫暖而不浮誇。
- 避免方向：大面積純黑、刺眼霓虹、過度閃爍、卡通化太空裝飾、低對比灰字。
- 裝飾必須服務內容閱讀；搜尋、篩選、店家資料優先於背景效果。

## 4. 地圖視覺規範

- 維持 Leaflet + OpenStreetMap standard raster tiles，不為單純換色額外引入地圖金鑰或新的供應商依賴。
- 地圖 tile pane 使用低彩度灰階反相濾鏡，轉為深石墨／海軍藍觀感；標籤與道路只保留必要對比。
- 店家位置使用香檳金星點作為預設 marker，各店家類型可以套用專屬低飽和分類色。
- 地圖縮放控制、彈出視窗、署名資訊需套用深色面板與香檳金重點。
- OpenStreetMap attribution 必須保持清晰可見並連結至版權頁；不得因套用濾鏡而隱藏或降低署名對比。
- 若未來更換底圖供應商，先檢查 API key、價格、快取、使用限制與 attribution，再修改本文件。

## 5. 元件樣式規則

- **頂部導覽**：半透明午夜藍玻璃質感，背景模糊；品牌標誌使用香檳金細框。
- **主視覺**：深藍星雲漸層，搭配低透明度星點與單一大型星芒；標題重點字使用香檳金至星雲紫漸層。
- **搜尋框**：深色玻璃卡片、金色細框；主按鈕使用低飽和香檳金漸層。
- **篩選器**：深藍卡片與清楚邊界，欄位具備明確 focus 狀態。
- **分類 chips**：依分類色設定描邊與選取光暈；未選取狀態保持低調。
- **店家卡片**：深藍紫漸層、細分類色上緣、輕柔外光；分類色不得大量填滿卡片。
- **詳情視窗**：深藍面板、香檳金細框，資料區塊以更深底色分組。
- **頁尾**：比主背景稍深，使用低亮度文字與香檳金連結。

## 6. 動態與可及性

- 星點只作為背景，移動速度極慢且低對比。
- 必須支援 `prefers-reduced-motion: reduce`；使用者偏好減少動態時，停用背景動畫與非必要轉場。
- 文字、按鈕、表單欄位保有清楚對比和可見的鍵盤 focus。
- 手機版維持一致色彩層級，避免過多星點、光暈或陰影影響效能。

## 7. 實作維護
- 設計 tokens 集中於 `:root`，避免散落重複色碼。
- 分類配色由 `data-type` 或穩定分類 ID 驅動，不能依卡片排序或隨機分配。
- 新增分類時，更新 `index.html`、此文件與 `AGENTS.md` 中相應的分類規則。
- 不得移除地圖 attribution；更換底圖前重新確認供應商政策。
